# Deployment

Code: `.github/workflows/build.yml`, `next.config.js`, `vercel.json`, `drizzle.config.ts`, `drizzle/`, `scripts/repair-migration-state.ts`, `ROADMAP.md`.

## Behavior

- Single branch `dev`. Planned: deploys to beta.curehht-ru.org (dynamic, Vercel, admin enabled).
- Production curehht-ru.org is a static export on GitHub Pages: workflow on push to `dev` deletes `src/app/admin` and `src/app/api`, builds with `NEXT_EXPORT_TYPE=export`, publishes `out/` to `gh-pages` with `CNAME`.
- Static build reads content from Postgres via `POSTGRES_URL` at build time.
- DB migrations are generated by drizzle-kit into `drizzle/` and applied with `pnpm migration:migrate`. `migration:repair-state` fixes the migration journal when it drifts.

## Rules

- Public pages SHALL work with `admin` and `api` directories removed.
- Public pages SHALL NOT depend on runtime-only features (sessions, route handlers) under `output: 'export'`.
- Migrations SHALL be committed together with the schema change.

- CI (`.github/workflows/build.yml`) runs typecheck, lint and tests on every push and PR. Deploy runs only on push to `dev`, after checks pass. Uses pnpm with a frozen lockfile.

## Known gaps

- ESLint reports warnings (`react-hooks/purity`, `react-hooks/refs`, unused vars); fix them when the UI is rebuilt.
- Roadmap items (daily/weekly rebuild from beta API, participant map) are unspecified; write a change file first.
